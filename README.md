# meridian-inclusion-suite

**Meridian Inclusion Suite: informal onboarding (T5), presumptive tax (T12), taxpayer education (T14) — agent app, USSD, white-label.**

## Purpose
Rails for bringing the informal economy into the tax net: agent-assisted onboarding, USSD-first flows, presumptive tax regimes, and taxpayer education. Ships as agent app, USSD gateway, and white-label embeds.

## Plane mapping
- **Execution plane:** informal onboarding (T5), presumptive tax filing/payment (T12)
- **Control plane:** taxpayer education content delivery (T14)
- Channels: agent app, USSD, white-label
- Presumptive bands sourced from signed packs in `meridian-rule-packs`; identity/ledger from `meridian-core-platform`.
